1. Перенести ярлык программы Ansible_gui на рабочий стол
2. Установить пакет python3-tk:
    sudo apt install python3-tk
3. Установить пакет python3-pyqt5
    sudo apt install python3-pyqt5
4. Для создания защифрованного SSH-ключа Написать в терминале: ssh-keygen -t ed25519 -C "administrator". Далее все пропускаем на Enter
5. Написать в терминале: ssh-copy-id имя_пользователя@ip_компьютера. Для передачи защифрованного SSH-ключа на целевой ПК. Пример: ssh-copy-id user@192.168.1.67
6. Запустить программу Ansible_gui и ввести логин и пароль администратора
7. Ввести названия нужных программ, айпи компьютеров куда нужно установить, параллельность
8. Нажать "Запустить установку"

ОПЦИОНАЛЬНО:
1. Установить sshpass (менее безопасно): sudo apt install sshpass
2. Убрать галочку "Использовать SSH-ключ"
